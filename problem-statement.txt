Project title: Forecasting Weekly NYC 311 Request Volume for Resource Planning
City departments need to anticipate where and when service requests will increase so they can prepare teams and allocate resources before demand peaks.
This project will develop a forecasting model using historical NYC 311 service requests to predict the number of requests expected during the upcoming calendar week for each department and geographic area. The initial analysis will use boroughs, with ZIP-code forecasts considered where sufficient data is available.
Historical requests will be aggregated by creation week, responding agency, and location. The model will use previous weekly request counts, recent demand trends, seasonal patterns, complaint-category patterns, and known calendar information such as holidays. Only information available before the forecast week will be used.
The target will be the number of new requests received during the next week for each department–area combination. Performance will be evaluated on later weeks using mean absolute error and comparison with simple forecasts, such as the previous week’s count.
The intended output is a forecast showing expected request volumes, uncertainty ranges, and areas likely to experience increased demand. These forecasts could support team scheduling, equipment preparation, and resource allocation. Staffing decisions would also account for complaint type, handling time, and existing backlog
